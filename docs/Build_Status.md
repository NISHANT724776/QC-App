# Build status — WFX Quality Controller (Angular)

Last updated after first full build. Project: `qc-app/` (Angular 22, standalone components, signals, SCSS, Angular Material + CDK).

## Run
```bash
cd qc-app
npm install
npm start          # http://localhost:4200  (mock data layer – any non-empty credentials work)
npm test           # 40 unit tests (rules, PDF writer, screenshot fixtures)
npm run build      # production build (initial ≈ 128 kB transferred)
```
First run: Register (any user/password/company id, URL like `https://qc.example.test`) → create a 4-digit PIN → Sync loads the sample requests.

## Document fidelity
The screens follow the provided screenshots and XAML: portrait and landscape UI sets (Profile > Landscape Layout, with the restart dialog), tab strip, dropdown results, teal tables, labels and seed data exactly as shown. See `Test_Report.md` §3 for the list of changes made to reach this.

Technical choices that are not visible to users: own tiny i18n service (instead of Transloco); request list paging is local (offline-first, server only touched by Sync); signals + native inputs in grids, Reactive Forms for Registration/PIN/Profile; PWA service worker/manifest not added yet.
